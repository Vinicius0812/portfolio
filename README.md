# Portfólio

Site estático do portfólio pessoal de Vinícius Araújo, com foco em freelas simples de desenvolvimento web, landing pages, correções, APIs simples, integrações, automações e manutenção de sistemas existentes.

## Estrutura

- `index.html`: estrutura principal da landing page
- `styles.css`: identidade visual e responsividade
- `script.js`: comportamento simples da interface

## Projetos destacados

- Elixir e Elixir API: app mobile de catálogo de drinks com API REST
- MailRecon: CLI educacional em Python para validação/recon ético de e-mails
- Alfred CLI: CLI em Go para automação de tarefas de projeto com YAML
- Experiência corporativa: case textual e anônimo sobre manutenção de sistema web

## Como testar

Abra `index.html` no navegador ou sirva a pasta com um servidor estático simples.

## Observações de segurança

- Não abrir nem publicar arquivos `.env`.
- Os projetos analisados ignoram arquivos de ambiente local; manter esse cuidado antes de divulgar novos repositórios.
