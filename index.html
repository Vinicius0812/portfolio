Projeto 01 • App mobile + API

01

Elixir: catálogo mobile de drinks

Aplicativo React Native com Expo para navegação em catálogo de coquetelaria, com busca, detalhes, autenticação, favoritos e fallback local quando a API não está disponível.

O que demonstra

  • App mobile com navegação, estado global e armazenamento seguro.
  • API REST com NestJS, Prisma, PostgreSQL, JWT e validação.
  • Integração entre front-end, back-end e modelagem de dados.

Projeto 02 • CLI educacional

02

MailRecon: validação ética de e-mails

CLI em Python para estudo de recon e validação de e-mails com fontes públicas, consultas DNS/MX, integração opcional com HIBP e relatórios em JSON e Markdown.

O que demonstra

  • Arquitetura modular de CLI com Typer e serviços separados.
  • Tratamento de erros, configuração por ambiente e testes com pytest.
  • Cuidado ético: sem validação intrusiva, abuso de SMTP ou enumeração não autorizada.
